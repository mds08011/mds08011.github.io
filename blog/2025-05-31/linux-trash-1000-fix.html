Deleting trash on Trash-1000 on Linux external drives

2025.05

When you delete files on an external drive in Linux, they don't disappear right away. Instead, they get moved into a hidden folder at the root of the drive called .Trash-1000 (the leading dot makes it hidden, and 1000 is usually your Linux user ID). Sometimes the permissions on an external drive lock that folder to root (the administrator account).

The Problem

Once .Trash-1000 is owned by root, I couldn't empty it from the regular desktop file manager. Those deleted files kept taking up space on the drive and also showed up as false positives when I ran a duplicate file scanner.

The Solution

You have to delete the folder from a terminal instead. Open one (Super + T in Pop!_OS or Ctrl + Alt + T on Ubuntu) and run df -h or lsblk first to check the exact path where your external drive is mounted. Then run the command below, replacing mds08011 and Elements with your own Linux username and drive name:

sudo rm -rf /media/mds08011/Elements/.Trash-1000

Careful: sudo runs the command as administrator (it will ask for your login password) and rm -rf permanently deletes that folder and everything inside it with no confirmation and no undo. Double-check the full path before hitting Enter. I ran into a No such file or directory error at first because I tried /media/Elements/ and forgot my username in the path.
