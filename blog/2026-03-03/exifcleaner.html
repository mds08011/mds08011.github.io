Removing photo GPS data with ExifCleaner

2026.03

GPS tags are preferred on photos 95% of the time for personal archiving and travel logs. However, when posting publicly, that data is a privacy concern. This tool, ExifCleaner, is useful for that specific requirement.

The Tool: ExifCleaner

ExifCleaner1 is an open-source GUI tool for scrubbing metadata from photos. It is cross-platform and uses ExifTool, abstracting the command line into a drag-and-drop interface.

Why ExifCleaner?

It processes images locally, ensuring photos are not uploaded to remote servers. It is fast, effective, and respects privacy.

Source code is available on the GitHub repository.2
