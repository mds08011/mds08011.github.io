Shutdown Window Planner

August 2026

A planned utility shutdown (such as replacing a valve, isolating a section of piping, or connecting a new water main to an existing line) has to finish within a fixed out-of-service window. That limit is usually set by storage tank capacity, permitted traffic lane closures, or the utility's customer-notification and outage rules [1]. Because shutdown tasks normally happen one after another, this calculator checks whether a sequence of steps plus a contingency buffer fits inside the allowable window.

You enter each task with its estimated duration di (in minutes or hours), the maximum allowable out-of-service window W (in hours), and a contingency buffer percentage b (% of planned work time). The calculator adds the sequential step durations for the planned duration P = ∑ di, computes the contingency buffer B = P × (b / 100), and finds the committed duration C = P + B, all converted to the same time unit (minutes). Slack against the window is S = W − C, where positive slack means the plan fits (GO) and negative slack means it exceeds the limit (NO-GO). If you enter a planned start date and time, the tool also computes start and end clock times for each step, marking times past midnight with +1d (next day), and draws a horizontal timeline with the window deadline marked.

Including the contingency buffer inside the allowable window accounts for delays in sequential work, where a single overrun pushes back every step that follows because there is no float (spare time) between consecutive tasks. Unexpected conditions, such as an existing valve that does not close tightly or pipe dimensions that differ from the as-built record drawing, consume that reserve. The planner also lets you flag hold points, which are steps whose duration is fixed and cannot be shortened by adding more crew (such as holding pressure for a hydrostatic test, waiting for laboratory water sample results, or waiting for an inspection). Return-to-service tasks such as pipe flushing and chlorine disinfection also take measurable time and should be listed as steps in the sequence [2].

Assumptions and limits
  • This planner models a strictly serial sequence where one step starts only after the previous step finishes. Parallel crews working on independent tasks are not modeled separately.
  • The utility's or owner's outage procedures, boil-water rules, and customer-notification policies govern the allowable window and required return-to-service testing.
  • For tight windows, setting a go/no-go checkpoint (a time before cutting into the existing main when work can be stopped and the existing pipe returned to service) and confirming backup options such as temporary connections or a bypass pump (a temporary pump routed around the work area) helps prevent overrunning the limit.
  • If the committed time exceeds the allowable window, splitting the work into shorter phased shutdowns, installing a temporary bypass, or requesting a longer window is safer than reducing the contingency buffer.

The planner runs directly in the web browser with no external scripts and saves entries on your device using browser storage (localStorage). It sits alongside the two-week look-ahead schedule on the tools page for hour-by-hour outage sequencing.
