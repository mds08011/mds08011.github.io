Preparing Images for Print Client-Side

December 2025

When you want to print several photos onto one sheet of paper without firing up a layout program, you can do it right in a browser with CSS print rules. I put a local copy of Simon Willison's Image Print Layout [1][2] on my site.

Pick or drop one or more images onto the page, choose the grid rows, columns, and fit mode, and click the Print button (or use Ctrl + P, or Cmd + P on macOS). Behind the scenes, the page updates a CSS <style> block with @media print rules so your browser lays the photos out cleanly on the printed page [2]. All images stay in your browser and are never uploaded.

The tool: Image Print Layout.

References

  1. Willison, S. "Photo print layout". Available: https://tools.simonwillison.net/image-print.
  2. Willison, S. "image-print.html Source Code" (Apache License 2.0, local copy). Available: https://github.com/simonw/tools/blob/main/image-print.html.
