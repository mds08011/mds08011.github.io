Two-Week Look-Ahead Gantt Chart

June 2026

This tool draws a short-range Gantt chart (a horizontal bar chart of scheduled tasks across calendar dates) for a construction look-ahead schedule (a near-term plan covering upcoming field work). Choose a window start date and window length (7, 14, or 21 days), then click + Add task to enter each task's name, optional crew or trade label, start date, duration, and duration mode (calendar days or working days). Tasks sharing the same crew label share a bar color from a four-color palette. Edit any cell directly to update the chart, delete a row with the × button, or clear all tasks with Clear all data.

In calendar-day mode, the inclusive finish date is end = start + (duration − 1) days, where start is the task start date and duration is the task length in calendar days (so a 5-day task starting Friday ends Tuesday). In working-day mode, the tool starts on start and advances one day at a time, counting only weekdays (Monday through Friday) until the count equals duration working days (so a 5-working-day task starting Friday spans Friday plus Monday through Thursday, ending the following Thursday). Each bar is drawn as one continuous block across shaded weekend columns so skipped weekend days stay visible. Entered YYYY-MM-DD strings are split into year, month, and day numbers and built as local dates instead of calling JavaScript's new Date("YYYY-MM-DD"), which treats date-only strings as UTC (Coordinated Universal Time) midnight and can shift displayed dates back one day in western timezones. Below the chart, the summary table reports how many tasks overlap the window, lists any tasks starting before or running past the window (marked with clipped bar ends), and identifies the busiest day by peak concurrent tasks.

All tasks and window settings are saved in browser localStorage (local storage on your device). This tool intentionally omits task predecessors (prior tasks that control when a following task can start), logic ties (automatic dependency links), float (allowable schedule slippage), and critical path (the longest linked sequence setting project completion) calculations. Those belong in the governing project master schedule (such as Primavera P6 or Microsoft Project).

Assumptions and limits
  • In lean construction (the Last Planner System), look-ahead planning supports make-ready planning: checking that materials, site access, design information, and crew assignments are ready before work starts [1].
  • When a task carries over across several consecutive look-ahead windows, it usually reflects an unresolved prerequisite rather than a simple date adjustment [1].
  • Working-day mode skips Saturdays and Sundays only. It does not automatically skip project-specific holidays.
  • Contractual dates, task dependencies, float, and critical path logic remain governed by the project master schedule.

The tool: Two-Week Look-Ahead Gantt.
