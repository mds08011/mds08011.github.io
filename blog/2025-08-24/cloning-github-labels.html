Cloning GitHub Issue Labels via CLI

August 2025

If you have a set of GitHub issue labels you like (with their colors and descriptions) and want the same ones in a new repository, retyping them one by one in the GitHub web interface is tedious.

The official GitHub CLI (gh, GitHub's command-line tool) has a built-in command for this: gh label clone [1]. It copies all the labels from one repository into another in one shot.

How to run it

Open a terminal. If you don't already have the GitHub CLI installed, install gh and sign in first with gh auth login (you need write access to the destination repository). Then run:

gh label clone simonw/datasette --repo my-org/my-new-repo

Replace simonw/datasette with the repository you want to copy labels from, and my-org/my-new-repo with your destination repository. By default, labels that already exist in the destination repo are skipped; add --force at the end if you want to overwrite them.

References

  1. GitHub CLI Manual. "gh label clone". Available: https://cli.github.com/manual/gh_label_clone.
