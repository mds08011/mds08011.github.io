Reading Old Emails with GoldFynch PST Viewer

2026.06

GoldFynch PST Viewer1 is a tool for reading legacy .pst Outlook archives without a full Microsoft Office installation.

It runs directly in the web browser, processing files locally without uploading them to a remote server. This respects the privacy of sensitive communications.

How to Use It

Using the tool involves visiting the site and loading the file locally. It provides DRM-free access to older communication records.

The interface allows browsing through the folder structure and reading individual emails. Browser-native search (Ctrl + F) can be used to search for specific keywords.

Looking for command-line alternatives?

For command-line extraction of attachments from a PST file, open-source tools like readpst are available. On a Debian-based Linux system, it can be installed and executed as follows:

sudo apt-get install pst-utils
readpst -D -M -b -o output_directory/ my_archive.pst
