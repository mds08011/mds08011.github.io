Reading Old Emails with GoldFynch PST Viewer

2026.06

GoldFynch PST Viewer1 is a tool for reading legacy .pst Outlook archives without a full Microsoft Office installation.

It runs directly in the web browser, processing files locally without uploading them to a remote server. This respects the privacy of sensitive communications.

How to Use It

Using the tool involves visiting the site and loading the file locally.

The interface allows browsing through the folder structure and reading individual emails. Browser find (Ctrl + F, or Cmd + F on macOS) searches the text currently visible on screen.

Looking for command-line alternatives?

For command-line extraction from a PST file on Debian/Ubuntu/Pop!_OS, open a terminal, install pst-utils (sudo asks for your password), create an output folder, and run readpst (replace my_archive.pst with your file; see man readpst for format and attachment options):

sudo apt-get install pst-utils
mkdir -p output_directory
readpst -D -M -o output_directory/ my_archive.pst
