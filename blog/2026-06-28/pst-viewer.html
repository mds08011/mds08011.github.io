Reading Old Emails with GoldFynch PST Viewer

2026.06

I've used GoldFynch PST Viewer1 to open old Microsoft Outlook email archive files (.pst files) without having Microsoft Outlook installed. In my experience it works well even on archives up to a few gigabytes in size.

Everything runs locally inside your web browser rather than uploading your emails to a remote server, which is important if you are opening old personal or work archives.

How to Use It

Open the GoldFynch PST Viewer page and drag your .pst file onto the window (or click to pick it from your computer).

Once loaded, you can click through the folder tree and read individual messages. Your browser's find shortcut (Ctrl + F, or Cmd + F on macOS) searches whatever text is currently visible on screen.

Command-line alternative (readpst)

If you want to extract a .pst file from the terminal on Linux instead of using a browser, readpst (in the pst-utils package) is an open-source option. I haven't used readpst myself, so check man readpst for the exact flags you need. On Debian, Ubuntu, or Pop!_OS, open a terminal and run (sudo will ask for your login password; replace my_archive.pst with your file):

sudo apt-get install pst-utils
mkdir -p output_directory
readpst -D -M -o output_directory/ my_archive.pst
