Generating JavaScript Bookmarklets

October 2025

A bookmarklet is a small piece of JavaScript saved as a regular browser bookmark (starting with javascript: instead of https://). Unlike a browser extension, it only runs on the current tab when you click it. I put a local copy of Simon Willison's Bookmarklets page [1][2] on my site.

The page includes a handful of small utilities, such as listing every section anchor (id) on a page so you can grab deep links, or opening a popup showing the current page's rendered HTML source [2].

To install one on desktop, make sure your browser's bookmarks bar is visible and drag any bookmarklet link from Bookmarklets onto the bar. On mobile (or if dragging is awkward), copy the code, create a new bookmark, and paste the javascript:... line into the bookmark's URL field.

References

  1. Willison, S. "Bookmarklets Collection". Available: https://tools.simonwillison.net/bookmarklets.
  2. Willison, S. "bookmarklets.html Source Code" (Apache License 2.0, local copy). Available: https://github.com/simonw/tools/blob/main/bookmarklets.html.
