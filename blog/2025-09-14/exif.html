Viewing EXIF Data Locally in the Browser

September 2025

Photos taken on phones and cameras usually carry hidden EXIF (Exchangeable Image File Format) metadata, including camera settings, timestamps, and often exact GPS (Global Positioning System) coordinates. If you want to check what metadata is inside a photo without uploading it to a third-party website, I adapted a local copy of Simon Willison's EXIF Data Viewer [1][2].

Drag and drop a JPEG onto the page (or pick one with the file picker). The page reads the file locally in your browser using the exif-js library (loaded from cdnjs [3]), lists all the EXIF tags it finds, and converts GPS coordinates from Degrees/Minutes/Seconds into regular decimal latitude and longitude [1][2].

The tool: EXIF Data Viewer.
