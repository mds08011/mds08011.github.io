A Local SVG Sandbox

November 2025

SVG (Scalable Vector Graphics) files are XML text under the hood and can contain JavaScript. When you load an SVG inside an HTML <img> tag using a Base64 data URI (embedding the image data directly inside the tag's src attribute), browsers block any scripts or onclick handlers inside the SVG from running.

I put a local copy of Simon Willison's SVG Base64 Embedding Sandbox [1][2] on my site as a quick read-only demo. It shows a few example SVGs embedded in <img> tags and uses JavaScript's atob() function to decode and print the raw SVG markup next to each one so you can inspect the source and see that embedded scripts do not fire [2].

If you want to convert your own SVG markup into a data URI (either Base64 or URL-encoded), see the companion SVG Data URI Encoder.

The tool: SVG Base64 Embedding Sandbox.
