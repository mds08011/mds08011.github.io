Reading TIFF Orientation Tags Client-Side

January 2026

Phone cameras often save JPEG photos sideways and store a small EXIF orientation tag (TIFF tag 0x0112) telling viewers which way to rotate the picture. When a photo shows up rotated the wrong way in some app, checking that tag usually explains why. I put a local copy of Simon Willison's TIFF Orientation Reader [1][2] on my site.

Select or drop a JPEG onto the page. Instead of pulling in an external EXIF library, the script reads the file's bytes directly in your browser using FileReader and DataView, locates the EXIF header (Exif\0\0), checks the byte order (little endian or big endian), and prints the orientation value (for example, Normal or Rotated 90° CW) along with debug output [2].

The tool: TIFF Orientation Reader.

References
