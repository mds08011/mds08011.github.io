HTML Table Extractor

February 2026

Copying a table from a webpage and pasting it straight into a spreadsheet often mangles the columns and formatting. I put a local copy of Simon Willison's HTML Table Extractor [1][2] on my site as a quick way to pull clean data out of web tables.

Copy a table from a webpage, open HTML Table Extractor, and paste it (Ctrl + V, or Cmd + V on macOS) into the input box. The page parses the HTML table, tr, and td elements in your browser and lets you switch tabs to copy clean HTML, Markdown, CSV, TSV, or JSON without sending the pasted data to a server.

The tool: HTML Table Extractor.
