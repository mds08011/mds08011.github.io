Extracting Tabular Data from Hypertext Markup Language Documents

February 2026

Data migration tasks frequently involve the extraction of tabular arrays locked within unformatted Hypertext Markup Language (HTML) documents. Copy-and-paste procedures from rendered web pages into spreadsheet applications often result in structural failure, necessitating an intermediary processing step.

I have adapted Simon Willison's HTML Table Extractor [1][2] as the HTML Table Extractor tool on this site. The user pastes copied table content with standard clipboard commands (Ctrl+V, or Cmd+V on macOS) into the editable input area.

The client-side scripts parse the Document Object Model (DOM), traversing table, tr, and td nodes. The logic handles nested cells and outputs the table in HTML, Markdown, CSV, TSV, or JSON formats.

The tool runs locally in your browser at HTML Table Extractor without uploading pasted tables to a server.

If you save the JSON output to a file (for example extracted-data.json), you can filter fields from a terminal using jq (install via sudo apt install jq on Debian/Ubuntu/Pop!_OS; replace .value with an actual column name):

jq '.[] | .value' extracted-data.json
