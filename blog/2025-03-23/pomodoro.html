A Vanilla JavaScript Pomodoro Timer

March 2025

A Pomodoro timer is a simple work timer (usually 25 minutes on, followed by a short break). Most web timers require an account or are covered in ads, so I put a local copy of Simon Willison's single-file Pomodoro Timer [1][2] on my site.

To use the Pomodoro Timer, type a short goal into the text box and click Start (or press Space when your cursor is outside the text box). It tracks the countdown using the browser's clock (Date.now()) and saves your finished sessions in your browser's localStorage so the log is still there if you refresh the page [2].

The tool: Pomodoro Timer.

Viewing the raw saved session data

Past sessions already appear on the page below the timer. If you want to see the raw stored data, open your browser's Developer Tools (F12, or Ctrl + Shift + I / Cmd + Option + I on macOS), switch to the Console tab on the timer page, and run:

window.localStorage.getItem('pomodoroSessions')
