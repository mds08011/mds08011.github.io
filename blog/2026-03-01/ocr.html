Running Tesseract OCR Locally in the Browser

March 2026

Implementing client-side optical character recognition (OCR) mitigates the privacy and bandwidth constraints typically associated with server-based text extraction. By utilizing a JavaScript compilation of the Tesseract OCR engine, it is possible to parse textual data from rasterized images and Portable Document Format (PDF) files entirely within the local execution environment.

The implementation relies on PDF.js to convert PDF documents into individual rasterized canvases, followed by Tesseract.js processing the visual data to yield a string extraction. This approach avoids uploading sensitive documents to a remote server. A local copy adapted from Simon Willison's tool [1][2] is available at Browser OCR.

Users can select a file or press Ctrl + V (Cmd + V on macOS) to paste an image directly into the page. Simon Willison's original TIL post shows a shorter browser-console Tesseract.js example for page images [3].

Local dependency verification

To check from a terminal that the Tesseract.js CDN script is reachable (do not type the $; curl -I fetches headers only and 200 means OK):

$ curl -I https://cdn.jsdelivr.net/npm/tesseract.js@5/dist/tesseract.min.js
HTTP/2 200 
content-type: application/javascript; charset=utf-8
