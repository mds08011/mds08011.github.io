OpenStreetMap Water Infrastructure Tags and Overpass Query Builder

July 2026

This page combines a reference table of common OpenStreetMap (OSM) tags for surface-visible water and wastewater infrastructure with a query builder for Overpass QL (Overpass Query Language, the query language used to search OSM data) [1][2]. In OpenStreetMap, map features are stored as nodes (points), ways (lines or polygons), or relations (groups of objects) and described with key=value tags. The reference covers fire hydrants, sewer and storm manholes, surface-visible valves, water towers, pumping stations, treatment plants, open ditches, culverts, and retention or detention basins.

The reference also summarizes standard OSM editing conventions [1]. Lifecycle prefixes (construction:*, disused:*, abandoned:*, demolished:*) keep inactive or unbuilt facilities from appearing as active assets. Changeset comments (short notes attached to a batch of edits) record what was mapped and the source, such as source=survey. Where a stream or ditch passes through a culvert under a road, the convention is to keep the waterway line continuous and tag the underground section with tunnel=culvert and layer=-1 rather than breaking the waterway.

Given a tag preset (or custom key=value) and a geographic bounding box (bbox), the builder outputs a standard Overpass QL query: [out:json][timeout:25]; nwr["key"="value"](S,W,N,E); out geom;. Here nwr searches nodes, ways, and relations, ["key"="value"] filters for matching tags (such as emergency=fire_hydrant), (S,W,N,E) specifies the bounding box in decimal degrees (south latitude, west longitude, north latitude, east longitude), and out geom; returns matching features with their coordinates. You can copy an S,W,N,E bounding box from the tile calculator, or use the map extent directly in Overpass Turbo [2]. To run the query, open Overpass Turbo [2], paste the text into the left-hand code editor, and click Run (the Wizard button can also draft simple queries from plain-text keywords).

Only surface-visible features observed in person or derived from OSM-compatible open sources should be added to OpenStreetMap. Do not copy buried pipe alignments, depths, or asset attributes from proprietary maps, restricted geographic information system (GIS) datasets, or as-built drawings (construction record drawings showing installed underground utilities) without explicit permission to publish under OSM's license. Before bulk edits or imports, verify current tag definitions on the OSM wiki [1], check actual tag usage counts on taginfo [3], and follow the OSM organized editing and import guidelines [4].

Notes and limits
  • Overpass QL variations: Use ["key"~"regex"] to match tag values with a regular expression (pattern match). Placing multiple [...] filter brackets next to each other combines them with logical AND (all conditions must match). Replace (S,W,N,E) with (around:50,lat,lon) to search within a 50-meter radius of a point, or replace out geom; with out count; to return only feature counts.
  • Browser storage: The tool is a single HTML page written in plain JavaScript that runs offline and saves query builder inputs in browser localStorage (local storage in the browser on your device).
