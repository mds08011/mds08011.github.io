Creating Quick Screen Recordings with gifcap

2026.06

I've used gifcap1 when I want a quick screen recording saved as a GIF. Everything runs locally in your browser (using WebAssembly to encode the video on your machine rather than uploading your screen capture to a server), and the project is open-source.2

How to Use It

Open gifcap.dev, click Start Recording, and pick the window or screen when your browser prompts for permission.

When you're done, click Stop in gifcap (or use your browser's stop-sharing bar). From there you can trim the start and end of the clip and save the GIF.

Running it Locally

I have only used the hosted website myself, not a local copy. Because the code is open-source on GitHub, you can also download ("clone") the repository and run it locally if you don't want to depend on the live site staying up.

Terminal commands to run gifcap locally

Open a terminal (requires git and Node.js/npm; check the repository README if the WebAssembly encoder needs a build step):

git clone https://github.com/joaomoreno/gifcap.git
cd gifcap
npm install
npm run dev

There is also a Hacker News thread with background on how the browser-side encoder works.3
