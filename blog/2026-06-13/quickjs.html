Running QuickJS via WebAssembly

June 2026

QuickJS is a small, standalone JavaScript engine. Compiled to WebAssembly (WASM, a format for running compiled code inside a web browser), it lets you run untrusted JavaScript snippets in an isolated sandbox that cannot touch the host webpage or its DOM. I put a local copy of Simon Willison's QuickJS in WebAssembly page [1][2] on my site.

Type or paste JavaScript into the editor and press Ctrl + Enter (Cmd + Enter on macOS) or click the run button. It runs the code inside quickjs-emscripten [3] using vm.evalCodeAsync(), wires up console.log() and a synchronous fetch helper, and stores your current script in the URL hash so you can bookmark or share a snippet [2].

The tool: QuickJS in WebAssembly.
