Fixing NTFS/exFAT Superblock Mount Errors on Pop!_OS

January 2025

When I plug an external USB hard drive (like a WD Elements) into Pop!_OS and get the error wrong fs type, bad option, bad superblock, it usually comes down to one of two things: either the drive is NTFS and wasn't safely ejected from Windows (leaving a "dirty flag" set on the filesystem), or the system is missing exFAT support.

Both fixes below run in a terminal. On Pop!_OS, open one by pressing Super + T (the Windows key plus T) or opening Terminal from the applications menu. With the drive plugged in, run lsblk -f to see its partition name (something like sdb1) and filesystem type (ntfs or exfat). Commands starting with sudo run with administrator privileges and will ask for your login password without showing characters as you type.

Fix 1: Clearing the dirty flag (NTFS)

If the drive uses NTFS (the default Windows filesystem) and was unplugged without safely ejecting it, Windows marks it as "dirty" and Linux refuses to mount it. You can clear that flag with ntfsfix (if the terminal says ntfsfix isn't found, install it first with sudo apt install ntfs-3g):

sudo ntfsfix /dev/sdb1

Replace sdb1 with the actual partition name you saw in lsblk -f.

Fix 2: Installing exFAT support

If the drive uses exFAT (common on drives shared between Windows and macOS) and Pop!_OS won't mount it, install the exFAT package using apt (the package manager on Pop!_OS/Ubuntu):

sudo apt install exfatprogs

On older Pop!_OS or Ubuntu releases, the packages were named exfat-fuse and exfat-utils instead: sudo apt install exfat-fuse exfat-utils.

Once the command finishes, unplug the drive and plug it back in. It should mount normally.
