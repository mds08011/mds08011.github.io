How the Numbers Are Derived

The math

D_mandrel = base ID × (1 − deflection/100)

Inverse: deflection = (1 − D_mandrel / base ID) × 100

The base ID is the standard's average ID — nominal OD minus two average walls, adjusted for tolerances — which is why an "8-inch" SDR 35 mandrel at 5% is 7.28 in., not 7.60 in. Using nominal ID oversizes the mandrel and fails good pipe.

Test rules that ride along with the size
  • Deflection testing is for flexible pipe (PVC, HDPE, some fiberglass) — it's a check on embedment quality, since a flexible pipe deflects to whatever shape its bedding allows.
  • The mandrel should be rigid, with an odd number of legs (typically 9) so it can't align two legs across a single flat, and pulled by hand — no winches. If it takes a comealong, the pipe fails.
  • Most specs require the test no sooner than 30 days after backfill (or after final backfill loads are in place) so initial deflection has developed.
  • Proving ring: verify the mandrel against a proving ring or micrometer before the test — mandrels get dropped and legs get bent.
  • A failed segment usually means re-excavation and re-compaction of haunching — which is why watching the haunch compaction during installation is cheaper than any mandrel.
