OSM Water Infrastructure Tag Reference & Overpass Query Builder

A tagging cheat sheet for the infrastructure a water/wastewater engineer actually notices on the street, plus a small Overpass QL builder for querying what's already mapped. Runs entirely offline; the query builder persists in this browser via localStorage.

The wiki governs: OSM tagging is a living convention — tags gain and lose favor, and regional practice varies. This page is a starting point for the common, stable cases; before any mass edit, import, or unfamiliar tag, check the current wiki page (and taginfo for real-world usage counts). When in doubt, tag conservatively, add a note=*, and let the local community weigh in. Also: never copy from Google Maps, county GIS with restrictive licensing, or as-builts you don't have the right to publish — OSM requires compatible sources (your own survey, Bing/Esri imagery where permitted, open-licensed data).

The valve row above shows the honest state of things: some utility features have settled tags, others are still contested — which is exactly why the wiki check matters. Anything not surface-visible and not open-licensed generally shouldn't be mapped at all.

Syntax & lifecycle patterns worth knowing
  • Tags are key=value; multiple values use semicolons (ref=A;B) but sparingly — separate features usually beat semicolon lists.
  • Lifecycle prefixes: construction:man_made=pumping_station (being built), disused:* (intact but unused), abandoned:*, demolished:*. A facility under construction should never carry the live tag — routers and data consumers believe you.
  • source=survey / source=local knowledge on the changeset; note=* talks to other mappers; fixme=* flags known problems.
  • ref=* is the bridge between OSM and the utility's asset IDs — enormously useful, but only where the ID itself is publishable.
  • Changeset comments: say what and where ("added hydrants and sewer manholes, Foo St between 1st and 3rd, field survey"). Future-you doing QA will be grateful.

Notes

Why map utility infrastructure at all

Hydrants in OSM have genuine emergency-response value and are unambiguous street furniture. Manhole covers are honest, surveyable, surface-visible facts — and a mapped pattern of sewer manholes is a legitimate public record of where public infrastructure runs, assembled from what anyone can see from the sidewalk. The line to respect: surface-visible features observed in person are fair game; buried alignments, depths, and anything from restricted as-builts or licensed GIS are not — both for licensing reasons and because publishing detailed utility data you hold in a professional capacity is a professional-judgment question before it's a mapping one.

Overpass QL beyond the builder

The generated query is the template worth memorizing: nwr[key=value](bbox);out geom;. Variations: ["key"~"regex"] for pattern matching, multiple filter brackets AND together, around:50,lat,lon instead of a bbox for proximity, and out count; when you just want numbers. The Overpass Turbo wizard writes decent queries from plain English if the syntax fights back.
